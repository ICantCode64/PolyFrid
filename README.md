## Dependencies
- Node.js

## How to use
1. Download all of the files.
2. In the folder with package.json run ``npm -i``.
3. Join 2.0 polytoria game.
4. Run ``node cmd.js``.
5. Wait for ``lua_State: 0x??????``.
6. After you see it, execute any script by typing it into the prompt.
